## Generation assumptions
- The data was generated, not collected from real users. Spending patterns, failure rates and regional shares are assumptions, not real-world evidence.
- Errors (typos, missing values, extreme amounts) were added on purpose to practise data cleaning.
- We used ChatGPT to generate the data which we will be using in this project.

## Limitations
- Covers one year only (2025) and one country (Kenya).
- Anonymised: no names, phone numbers or account details.
- Findings describe this dataset only and should not be generalised without caution.
